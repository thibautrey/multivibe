# Harness artwork provenance

These files are unmodified product artwork used only to identify a harness selected by the user.

- `multivibe.png`: MultiVibe mark from `assets/brand/raster/multivibe-mark-1024.png` in this repository.
- `hermes-light.png` and `hermes-dark.png`: Hermes Agent official light/dark marks from `website/static/img/logo.png` and `logo-dark.png` in NousResearch/hermes-agent. Hermes Agent is MIT licensed; the pinned license is in `native/ios/AgentHarness/upstream/hermes/LICENSE`.
- `pi.svg`: Pi official mark from `https://pi.dev/logo-auto.svg`, referenced by the installed `@earendil-works/pi-coding-agent` README. Pi is MIT licensed; its pinned notice is in `native/ios/AgentHarness/licenses/pi.txt`.

Do not redraw, recolor, or substitute these marks with SF Symbols.
