## Audio and live voice

A new **Extensions → Audio** workspace configures the speech pipeline behind a
local GPT-Live-compatible voice server.

- Pick the reasoning, transcription, synthesis, and output-voice models in one
  compact form.
- Test the local server's health endpoint and see the exact server environment
  to start it with.
- The built-in audio plugin is enabled by default; tokens stay in the host
  environment and are never stored in the dashboard.

See `docs/audio-plugin.md` for the architecture, model mapping, server setup,
delegation modes, and limits.
