# Harness artwork provenance

These assets are unmodified product artwork used only to identify the selected harness.

- `HarnessHermes`: official light/dark Hermes Agent marks already vendored in `packaging/macos/resources/harnesses`.
- `HarnessPi`, `HarnessOpenCode`, `HarnessOpenClaw`, `HarnessGoose`, and `HarnessOpenHands`: official artwork already vendored in `packaging/macos/resources/harnesses`; see that directory's `README.md` for exact upstream sources and licenses.
- `HarnessLibreChat`: official `client/public/assets/logo.svg` from `LibreChat-AI/LibreChat`, retrieved 2026-10-26 from the upstream `main` branch (MIT).

Do not redraw, recolor, or substitute these marks with SF Symbols.
